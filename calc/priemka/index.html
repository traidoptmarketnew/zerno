Калькулятор приёмки зерна — съём по качеству

Универсальный расчёт по культурам с автосъёмом. Съём всегда ≥ 0 и только уменьшает цену. Направление показателя: больше → хуже меньше → хуже

Норму и ставку можно править прямо в таблице — расчёт пересчитывается на лету.
